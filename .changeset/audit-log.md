Audit log (Enterprise): sign-ins and failed attempts, reviews, ignore regions and thresholds, comments, users, roles, invitations, project settings, API tokens, notification channels and license changes — with person or token, project, old and new values, IP address and browser, never secrets. Searchable and filterable under *Audit log*, exportable as CSV or JSON Lines, append-only with a hash chain and an integrity check. First code under `ee/` (optik Enterprise License). The web UI now passes the client's address and browser on to the API.
