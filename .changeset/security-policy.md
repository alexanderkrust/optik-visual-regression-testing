Operators can publish their security contact as `/.well-known/security.txt` (RFC 9116) by setting `SECURITY_TXT_CONTACT` (plus optional `SECURITY_TXT_POLICY`, `SECURITY_TXT_ENCRYPTION`, `SECURITY_TXT_ACKNOWLEDGMENTS`, `SECURITY_TXT_LANGUAGES`). New: SECURITY.md with the reporting process and supported versions, a yearly LTS release with 18 months of security fixes (docs/releases.md), an upgrade guide (docs/upgrading.md), and release notes that list security fixes and upgrade notes first.
